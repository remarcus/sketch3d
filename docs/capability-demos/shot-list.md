## Tutorial captures (45–90 seconds each)

### Place a guide, draw, mirror, and export

Prerequisites: verified saved/temporary guide workflow, mirror, planar shapes, and relevant export path. Use an original storefront or lantern fixture.

1. Start from a clean scene and explain the active plane.
2. Place/activate a guide and show its axes and surface.
3. Draw a straight detail and an ellipse.
4. Enable mirror and draw a symmetric ornament.
5. Orbit and inspect; undo one action and redo it.
6. Export an image or GLB and explain the included content.

### Trace a reference and refine the drawing

Prerequisites: verified reference board/image plane, selection/appearance editing, and partial eraser. Use an original or licensed window/door photograph.

1. Import the reference and fit it in the reference board.
2. Place a 3D image plane and activate **Draw here**.
3. Trace a straight edge and an ellipse with planar tools.
4. Select the stroke, change its appearance, and erase part of an extra line.
5. Hide or lock the image and inspect the retained ink.
6. Save, reload, and explain how the source image asset travels with the drawing.
